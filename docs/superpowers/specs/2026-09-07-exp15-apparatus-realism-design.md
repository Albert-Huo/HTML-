# 实验 15 器材真实性优化设计

## 目标

在不改变实验结论与四关结构的前提下，修正弹簧测力计、夹具和刮刀的外形、位置与受力关系，并移除画布底部重复信息。

## 已确认方案

- 采用“真实受力轴线重构”：两块金属块、连接环、拉线与横置弹簧测力计保持同轴。
- 测力计采用 0–10 N 可视量程，包含绿色外壳、读数窗、弹簧、刻度、指针、拉环与挂钩；读数、指针及弹簧形变共用 `pullN` 状态。
- 夹具采用底座、固定钳口、移动压盘、螺纹丝杆与 T 形手柄；手柄仍通过原有画布拖拽控制 `clampLevel`。
- 刮刀采用木柄、铆钉、刀颈和金属刀片，仍使用原有拖拽状态与双侧打磨阈值。
- 修正操作链为“打磨 → 压紧 → 回松夹具但保持贴合 → 小拉力/大拉力测量”。压紧质量单独保存，回松夹具不得清除吸附状态。
- 删除画布下方“打磨进度”“压紧度”和器材说明；实验状态只在顶部观察条显示。

## 响应式布局

- 桌面端：金属块居中偏左，横向测力计位于右侧并与块中心线同高，夹具框架围绕样件但不遮挡测力计。
- 390/320 窄屏：缩短测力计与夹具丝杆，适当缩小金属块；仍保持同轴连接，不通过斜拉线解决空间问题。
- 移动端器材可见尺寸与命中尺寸分离：夹具手柄和刮刀的触控热区不小于约 44 px。

## 验收标准

- 0 N、3 N、7 N 时数字读数、刻度指针与弹簧形变一致，7 N 不超量程。
- 夹具压紧后必须回松，才能执行测力；3 N 未分离、7 N 分离，手动与自动演示同源。
- 桌面、390×844、320×568 下，测力计、夹具、刮刀和顶部观察条互不遮挡，且没有画布底部重复文案。
- 重置、重复实验、自由模式和自动演示无控制台错误。
